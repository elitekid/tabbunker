Get your saved tabs back from an export file

Paste a OneTab export, a Session Buddy JSON, or a TabBunker backup. Everything runs inside this page. Nothing is uploaded anywhere.

Read this first. This page can only rebuild a list from a file you still have (an export, a backup, a copy). If your saved list is already empty and you never exported it, this page cannot bring it back. Before you uninstall or reinstall anything, look for an export file, check your browser's other profiles, and check Time Machine or File History for the browser profile folder.

Accepted: OneTab "Export" text (one URL per line, optional " | title", blank line between groups), Session Buddy JSON export, TabBunker backup JSON (Downloads/TabBunker/tabbunker-latest.json or a dated tabbunker-*.json).

2. Result

    HTML bookmarks can be imported into any browser (Bookmarks manager, Import). The TabBunker JSON can be imported into the TabBunker vault with a merge preview.

    3. Optional: keep it from happening again

    TabBunker is a free, open-source extension that saves all tabs in one click and writes a backup file to your Downloads folder automatically. Close your tabs. Keep a backup. No account, no server. Source code and install links

    How to verify nothing leaves your browser

    Open the developer tools (F12), go to the Network tab, then paste your data and click Rebuild. No request is made. The page is a single HTML file plus three small JavaScript modules, all loaded once from the same site. You can also save this page and run it from your disk.
