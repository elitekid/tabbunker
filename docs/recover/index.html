Read the file that is still on disk

디스크에 남은 파일을 다시 읽기

After the extension is gone, the vault inside the browser is gone with it. If a JSON or text file remains, this page reads that file here. Nothing is uploaded.

확장이 지워지면 브라우저 안의 보관함도 함께 사라집니다. JSON이나 텍스트 파일이 남아 있으면 이 페이지가 그 파일을 여기서 읽습니다. 아무것도 올리지 않습니다.

No file, no recovery. This page rebuilds a list from a file you still have. It does not search the browser profile, and it does not recreate a list that was never exported. If the other extension is still installed, export first and follow the import guide. If the list is already empty, the recovery guide is the place to look for a leftover file.
파일이 없으면 복구할 수 없습니다. 이 페이지는 아직 가지고 있는 파일로 목록을 다시 만듭니다. 브라우저 프로필을 검색하지 않고, 한 번도 내보내지 않은 목록을 만들어 내지도 않습니다. 다른 확장이 아직 설치돼 있다면 먼저 내보내고 가져오기 안내를 따르세요. 목록이 이미 비어 있다면 복구 안내에서 남은 파일을 찾습니다.
Order, once the extension is already gone 확장을 이미 지운 뒤의 순서
  1. Do not look for the list in the extension screen. Uninstalling removes the extension's storage. The file, if it exists, is on disk.
  2. Look for an export you saved, or a TabBunker JSON in the TabBunker folder inside Downloads. The usual names are tabbunker-latest.json and tabbunker-YYYYMMDD-HHMM.json. There is no file when backup was off, the download was canceled, or the file was deleted.
  3. If there is no file, stop. Reinstalling does not create one.
  4. If there is a file, paste it or choose it in the box below. The reading stays in this page. The network check further down is how you can see that no request is sent.
  5. What comes back is links and titles. A TabBunker file also keeps group titles, including groups that were in Trash, because this page lists every group in the file. The vault's Import skips trash groups and counts them as excluded. OneTab text groups are titled Imported 1, Imported 2. A login, a form, and unsaved text from those tabs are not in the file, so they do not come back.
  6. Download the list or copy the links. To put a TabBunker JSON back into the extension, reinstall, open the vault, choose Import, and read the preview before Merge or Replace All.
  1. 확장 화면에서 목록을 찾지 마세요. 삭제하면 확장 저장소가 사라집니다. 파일이 있다면 디스크에 있습니다.
  2. 직접 저장한 내보내기, 또는 다운로드 폴더 안 TabBunker 폴더의 TabBunker JSON을 찾습니다. 흔한 이름은 tabbunker-latest.json과 tabbunker-YYYYMMDD-HHMM.json입니다. 백업이 꺼져 있었거나, 다운로드가 취소됐거나, 파일을 지웠다면 파일이 없습니다.
  3. 파일이 없으면 여기서 멈춥니다. 다시 설치해도 파일이 생기지 않습니다.
  4. 파일이 있으면 아래 칸에 붙여 넣거나 고릅니다. 읽기는 이 페이지 안에서 끝납니다. 요청이 나가지 않는 것은 아래 네트워크 확인으로 볼 수 있습니다.
  5. 돌아오는 것은 링크와 제목입니다. TabBunker 파일은 그룹 제목도 남기며, 휴지통에 있던 그룹도 포함합니다. 이 페이지는 파일 안의 그룹을 모두 보여 주기 때문입니다. 보관함의 가져오기는 휴지통 그룹을 건너뛰고 제외 수에 넣습니다. OneTab 텍스트 그룹 제목은 Imported 1, Imported 2입니다. 그 탭의 로그인, 폼, 저장하지 않은 글은 파일에 없으므로 돌아오지 않습니다.
  6. 목록을 받거나 링크를 복사합니다. TabBunker JSON을 확장으로 다시 넣으려면 다시 설치한 뒤 보관함에서 가져오기를 고르고, 합치기나 전체 바꾸기 전에 미리보기를 읽습니다.

    How to verify nothing leaves your browser 브라우저 밖으로 나가지 않는지 확인하는 방법

    Open the developer tools (F12), go to the Network tab, then paste your data and click Rebuild. No request is made. The page is a single HTML file plus three small JavaScript modules, all loaded once from the same site. Offline use requires saving the HTML and its modules together; saving this HTML alone is insufficient.
