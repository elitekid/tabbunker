# 용어표 (영어 ↔ 한국어)

UI 문구는 src/_locales/{en,ko}/messages.json 이 정본이다. 새 문구는 반드시 두 파일에 같은 키로 추가하고, 화면 코드에는 t('키') 또는 data-i18n="키"만 쓴다(하드코딩 금지).

| 개념 | 영어 | 한국어 | 비고 |
|---|---|---|---|
| 제품명 | TabBunker | TabBunker | 번역하지 않음 |
| 보관 화면 | Vault | 보관함 | "금고"는 쓰지 않음 |
| 탭을 닫아 보관 | Collapse | 접어 보관 / 접기 | 동작명은 "탭 접어 보관", 설정 묶음 제목은 "접기" |
| 보관 단위 | Group | 그룹 | |
| 다시 열기 | Restore / Restore All | 복원 / 모두 복원 | |
| 삭제 방지 | Lock / Unlock | 잠금 / 잠금 해제 | |
| 제목 변경 | Rename | 이름 바꾸기 | |
| 휴지통으로 | Delete | 삭제 | 휴지통으로 이동 |
| 영구 삭제 | Delete Forever | 완전 삭제 | |
| 휴지통 | Trash | 휴지통 | |
| 외부 데이터 읽기 | Import | 가져오기 | |
| 파일로 저장 | Export | 내보내기 | "보내기" 아님 |
| 가져오기 방식 | Merge / Replace All | 합치기 / 전체 바꾸기 | |
| 자동 저장 사본 | Backup | 백업 | |
| 저장 위치 | Downloads | 다운로드 폴더 | 영어 폴더명 그대로 노출하지 않음 |
| 고정 탭 | Pinned tab | 고정 탭 | |
| 주소 | URL | 주소 | 설정 문구에서는 "주소" |
| 가져온 그룹 기본 제목 | Imported N | 가져온 그룹 N | |
| 개수 | N tabs | 탭 N개 | |
| 쪽 | Page a / b | a / b 페이지 | |
