# 스토어 등록 설명문 (한국어)

## 이름
TabBunker

## 짧은 설명 (매니페스트 extDescription 과 같음, 크롬 132자 이내)
툴바에서 보관할 탭을 골라 닫고 언제든 다시 열어요. 다운로드 폴더에 백업 파일을 자동으로 남기고, 계정은 필요 없어요.

## 카테고리
생산성 > 도구

## 상세 설명

탭이 너무 많을 때 툴바의 TabBunker 아이콘을 누르면 작은 창이 열려요. 이 창의 탭을 전부 보관하거나, 남길 탭만 빼고 골라 보관할 수 있어요. 닫지 않고 목록에만 남기는 것도 돼요. 아이콘을 누르는 것만으로는 어떤 탭도 닫히지 않아요.

잘못 보관했으면 같은 창에서 바로 되돌리면 돼요. 보관한 탭은 그 창의 목록에서 탭 하나만, 또는 그룹 전체를 다시 열 수 있어요.

보관함이 바뀔 때마다 브라우저 안 이력이 갱신돼요. 기본으로 켜진 파일 백업을 사용하면 잠시 뒤 별도 JSON 사본도 저장해요.

- 브라우저 안: 최근 스냅샷 20개를 확장 안에 보관해요.
- 컴퓨터 디스크(파일 백업을 켰을 때): 다운로드 폴더 안 TabBunker 폴더에 JSON 파일로 저장해요. 확장을 초기화하거나 지우고 다시 설치해도 파일은 남고, 어떤 텍스트 편집기로도 열 수 있어요. 크롬·엣지에서는 저장할 때 다운로드 창이 뜨지 않아요. 파일 백업은 끌 수 있어요.

계정 없음, 서버 없음, 네트워크 요청 없음. 탭 목록은 사용자의 컴퓨터를 떠나지 않아요. 코드는 오픈소스예요.

설치 창에 최대 세 줄의 경고(방문 기록 읽기·다운로드 관리·사이트 아이콘 읽기)가 뜰 수 있어요. 저장한 주소는 기기 밖으로 나가지 않아요.

기능
- 툴바 창: 이 창의 탭 보관(닫기 또는 닫지 않기), 보관할 탭 고르기, 되돌리기, 보관한 탭 검색·열기·이름 바꾸기·잠금·삭제.
- 단축키(윈도우 기본 Alt+Shift+S)와 우클릭 메뉴: 고르는 과정 없이 이 창의 탭, 이 탭, 링크를 바로 보관해요.
- 보관함 전체 화면: 모든 그룹 검색, 탭을 그룹 사이로 끌어 옮기기, 휴지통, 백업 파일로 복구. 필요할 때만 열려요.
- 열기 전 확인: 탭이 30개 이상인 그룹을 모두 열 때는 먼저 물어봐요.
- 백업: 보관함이 바뀌면 브라우저 안 스냅샷을 갱신해요. 파일 백업을 켜 두면 다운로드 폴더의 tabbunker-latest.json을 변경 뒤 덮어쓰고, 한 시간에 최대 하나씩 날짜 파일을 남겨요(최근 30개). 마지막 파일 저장 시각은 툴바 창·보관함·설정에서 볼 수 있어요.
- 가져오기: OneTab 텍스트, Session Buddy JSON, TabBunker 백업 파일. 합치기 전에 미리보기, 되돌리기 한 번.
- 내보내기: TabBunker JSON, OneTab 호환 텍스트, 어떤 브라우저에도 넣을 수 있는 HTML 북마크.
- 크롬·엣지에서는 보관한 탭마다 파비콘을 보여 주고(브라우저 로컬 캐시만 사용), 파이어폭스는 도메인 첫 글자를 써요. 시스템 설정을 따르는 다크 모드.
- 휴지통: 삭제한 그룹을 30일 동안 되살릴 수 있어요.
- 크롬, 엣지, 파이어폭스 지원. 한국어와 영어 화면.

권한 설명
- 탭: 열린 탭의 주소와 제목을 읽어 저장하고, 닫고 다시 여는 데 써요.
- 저장소 / 무제한 저장소: 그룹과 백업 기록을 용량 제한 없이 로컬에 보관해요.
- 다운로드: 백업과 내보내기 파일을 다운로드 폴더에 써요. 어디로도 올리지 않아요.
- downloads.ui (크롬·엣지): 자동 백업 파일을 저장하는 동안만 다운로드 창이 튀어나오지 않게 잠깐 숨기고, 끝나면 바로 되돌려요.
- 알람: 백업과 매일 휴지통 정리를 예약해요.
- contextMenus: 우클릭 메뉴 항목 등록에만 써요.
- favicon (크롬·엣지): 목록 표시용으로 브라우저 로컬 파비콘 캐시를 읽어요. 네트워크 없음.

OneTab이나 Session Buddy에서 옮기기
기존 확장에서 데이터를 내보낸 뒤 TabBunker 보관함을 열고 가져오기를 눌러 내보낸 파일을 고르세요(OneTab 은 내보내기 텍스트를 .txt 파일로 먼저 저장하세요). 실제로 바뀌기 전에 무엇이 합쳐질지 미리 보여 줘요.
