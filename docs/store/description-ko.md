# 스토어 등록 설명문 (한국어)

## 이름
TabBunker

## 짧은 설명 (매니페스트, 크롬 132자 이내)
탭은 닫고, 백업은 남깁니다. 한 번에 탭을 보관하고 자동으로 로컬 백업하며 복원 전에 미리 봅니다.

## 카테고리
생산성 > 도구

## 상세 설명

탭이 너무 많을 때, 클릭 한 번이면 현재 창의 탭이 전부 닫히고 보관함에 그룹으로 저장됩니다. 탭 하나만 복원하거나, 그룹 전체를 복원하거나, 먼저 미리보기로 확인할 수 있습니다.

설치 창에 최대 세 줄의 경고(방문 기록 읽기·다운로드 관리·사이트 아이콘 읽기)가 뜰 수 있고, 저장한 주소는 기기 밖으로 나가지 않습니다.

TabBunker가 다른 점은 클릭 이후에 일어나는 일입니다. 모든 변경이 자동으로, 두 곳에 백업됩니다.

- 브라우저 안: 최근 스냅샷 20개를 확장 내부에 보관합니다.
- 컴퓨터 디스크: 다운로드 폴더 안 TabBunker 폴더에 JSON 파일로 저장합니다. 확장을 초기화하거나 지우고 다시 설치해도 파일은 남고, 어떤 텍스트 편집기로도 열 수 있습니다.

계정 없음, 서버 없음, 네트워크 요청 없음. 탭 목록은 사용자의 컴퓨터를 떠나지 않습니다. 코드는 오픈소스입니다.

기능
- 한 번에 접기: 툴바 아이콘 또는 Alt+Shift+S로 현재 창의 탭을 전부 그룹으로 보관.
- 보관함: 모든 그룹과 탭을 검색하고, 탭 하나 또는 그룹 전체를 복원하고, 그룹을 잠가 실수로 지워지지 않게 하고, 이름을 바꾸고, 탭을 그룹 사이로 끌어 옮기기.
- 복원 미리보기: 보관함에 모든 링크가 보이고, 탭이 30개 이상일 때는 먼저 확인합니다.
- 자동 백업: 브라우저 안 스냅샷과 다운로드 폴더의 tabbunker-latest.json 을 변경할 때마다 덮어쓰고, 한 시간에 하나씩 날짜 파일을 남깁니다(최근 30개). 마지막 파일 저장 시각을 보관함 상단에서 볼 수 있습니다.
- 가져오기: OneTab 텍스트, Session Buddy JSON, TabBunker 백업 파일. 합치기 전에 미리보기, 되돌리기 한 번.
- 내보내기: TabBunker JSON, OneTab 호환 텍스트, 어떤 브라우저에도 넣을 수 있는 HTML 북마크.
- 우클릭 메뉴: 이 탭 보내기, 링크 보내기, 이 창의 모든 탭 보내기를 페이지에서 바로 실행합니다. 보낸 탭에 대해서는 되돌리기가 됩니다.
- 크롬에서는 보관한 탭마다 파비콘을 보여 주고(브라우저 로컬 캐시만 사용), 파이어폭스는 도메인 첫 글자 아바타를 씁니다. 시스템 설정을 따르는 다크 모드를 지원합니다.
- 휴지통: 삭제한 그룹을 30일 동안 복구 가능.
- 크롬, 엣지, 파이어폭스 지원. 한국어와 영어 UI.

권한 설명
- 탭: 열린 탭의 주소와 제목을 읽어 저장하고, 닫고 다시 여는 데 씁니다.
- 저장소 / 무제한 저장소: 그룹과 백업 이력을 용량 제한 없이 로컬에 보관합니다.
- 다운로드: 백업과 내보내기 파일을 다운로드 폴더에 씁니다. 어디로도 올리지 않습니다.
- 알람: 백업과 매일 휴지통 정리를 예약합니다.
- contextMenus: 우클릭 메뉴 항목 등록에만 사용합니다.
- favicon (크롬만): 보관함 표시용으로 브라우저 로컬 파비콘 캐시를 읽습니다. 네트워크 없음.

OneTab이나 Session Buddy에서 옮기기
기존 확장에서 데이터를 내보낸 뒤 TabBunker 보관함을 열고 가져오기를 누르고 붙여 넣거나 파일을 고르세요. 실제로 바뀌기 전에 무엇이 합쳐질지 미리보기로 보여 줍니다.
